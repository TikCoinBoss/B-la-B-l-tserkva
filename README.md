# Біла Церква / Bílá Cerkev

Minecraft-style 3D browser game: a block copy of the village Bila Tserkva (Zakarpattia, Ukraine) with its real streets, the Tisa river and the border.
Works on a phone and on a computer, the interface is in Ukrainian, Czech and Romanian.

**Play:** open the GitHub Pages address of this repository (Settings → Pages) in a browser.

## Controls
- Computer: WASD to walk, mouse to look, Space to jump (twice to fly), left/right click to break/place, **P** for places and street teleport.
- Phone: left thumb to walk, right thumb to look, on-screen buttons for jump, break and place.
